# 奇妙搭档 · 我和孩子的亲子小游戏

**让科普变成游戏，让陪伴更有趣。**

一个面向 3–6 岁儿童的亲子互动益智游戏项目，一个随时掏出手机就能与小朋友一起玩，锻炼识数、记忆、模仿等能力的小游戏，希望大家玩得开心！

## 💡 为什么做这个项目？

市面上有很多儿童小游戏和早教产品，但大多是让孩子独自玩游戏，或者通过课程、绘本、答题等方式学习知识。

真正让家长和孩子一起参与，把科学知识、生活常识和益智教育融入游戏玩法的产品，其实很少。

所以，我想尝试一种不太一样的方式：

**把科普教育变成游戏，让孩子在玩中探索、在互动中学习。**

不再只是家长教、孩子学，而是家长和孩子一起玩、一起发现、一起解决问题。

## ✨ 项目特色

- **亲子互动：** 面向家长和孩子共同设计，不是让孩子独自面对屏幕。
- **寓教于乐：** 将科学、自然、生活常识、数学逻辑等知识融入游戏。
- **好玩有趣：** 用探索、解谜、匹配、搭建等玩法代替枯燥的知识问答。
- **年龄分层：** 3–4 岁侧重亲子互动与感知探索，5–6 岁侧重逻辑思考与自主解谜。
- **轻量体验：** 每款游戏独立完整，随时打开，几分钟就能享受一段亲子时光。


里面有 16 款游戏，我和孩子玩下来，像**森林快递员、小小采购员**等很不错。一个人说线索、一个人找东西，或者一起看清单、数数量，玩的时候能聊起来，大人也能参与进去。
